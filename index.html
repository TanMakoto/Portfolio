FaceQRity — Smart Attendance & AI Verification

โครงงานระบบเช็คชื่อเข้าชั้นเรียนและตรวจสอบตัวตนอัจฉริยะ (Dual-Mode Authentication) ที่ผสานสองเทคโนโลยีเข้าด้วยกันเพื่อแก้ปัญหาการเช็คชื่อแทนกันและการทุจริต:

  • Dynamic QR Code 60 วินาที: QR Code สร้างขึ้นเฉพาะบุคคลและผลัดเปลี่ยนอัตโนมัติทุกๆ 60 วินาที (Time-based Rolling QR) ป้องกันการบันทึกภาพหน้าจอส่งต่อให้เพื่อน
  • AI สแกนใบหน้า Realtime: ยืนยันตัวตนบุคคลผ่านกล้องเว็บแคม/CCTV ด้วย DeepFace (VGG-Face / RetinaFace) จับคู่โครงหน้าแบบเรียลไทม์ พร้อมตรวจจับโครงกระดูก 33 จุดด้วย MediaPipe
  • 5D Gait Metrics: วิเคราะห์ลักษณะและท่าทางการเคลื่อนไหวขณะเดิน (Hip/Ankle Balance, Leg Extension, Arm Swing, Torso Tilt) เพื่อเพิ่มความแม่นยำในการระบุตัวตน
  • Hands-Free Kiosk Mode: นักศึกษาเพียงเดินผ่านหน้ากล้อง ระบบจะทำการตรวจจับใบหน้าและบันทึกเวลาเข้าเรียนโดยอัตโนมัติทันที

ข้อมูลทั้งหมดถูกประมวลผลผ่าน FastAPI Backend (Titan Auth API) และบันทึกเข้าสู่ฐานข้อมูล MongoDB Atlas แบบเรียลไทม์ รองรับหน้าแอดมินสำหรับดูสถิติและส่งออกรายงาน Excel/CSV

เทคโนโลยีและสถาปัตยกรรม (Tech Stack):
MediaPipe Pose (33 จุด) DeepFace (VGG-Face) Dynamic QR (60s Cycle) Figma (UI/UX Design) MongoDB Atlas Python 3.11 FastAPI (Titan Auth API) React.js + Vite WebSocket Realtime Vercel Deployment Docker / Render
ฟีเจอร์เด่นของระบบ:
  • 🤖 ตรวจจับใบหน้า Realtime พร้อมแสดง AI Confidence Score (%)
  • ⏱️ Dynamic QR Code หมดอายุใน 60 วินาที ป้องกันการโกง 100%
  • 🚶 Hands-Free Walk-by Kiosk Mode ไม่ต้องสัมผัสอุปกรณ์
  • 📊 Attendance Analytics Dashboard (ตรงเวลา / มาสาย / ขาด)
  • 📥 ส่งออกข้อมูลบันทึกเวลาเข้าเรียนเป็น Excel (.xlsx) / CSV
  • 👨‍🎓 ระบบจัดการรายชื่อนักศึกษา Admin Portal
